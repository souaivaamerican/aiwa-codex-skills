# AIWA Codex Skills

Biblioteca de agentes da AIWA para Codex Web. As skills internas abaixo são instruções textuais sem scripts executáveis. Skills de terceiros só entram após auditoria.

## Uso no Codex Web
Abra este repositório como projeto/ambiente do Codex. O arquivo AGENTS.md define as regras do projeto; skills em `.agents/skills/<nome>/SKILL.md` podem ser descobertas conforme o ambiente suportado. A simples publicação no GitHub NÃO instala globalmente skills no Codex Web. Confirme a descoberta no ambiente de execução.

## Política
Não executar scripts de skills externas sem revisão; não copiar segredos; exigir evidência de segurança e revisão humana. A skill externa `superagent-ai/skills/skills/skill-security` está em quarentena lógica, ainda não instalada nem aprovada.
